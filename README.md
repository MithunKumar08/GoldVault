GoldVault

A React app where customers save money as gold (by weight) and redeem their
balance for jewellery once they've saved enough. Built with Vite + React and
React Router.

Features


Login — split-panel sign-in screen
Dashboard — gold balance, savings plans, recent activity, and a
redeemable jewellery catalogue
Invest — pick a savings plan and amount, with a projected return, then
continue to payment
Transactions — full ledger of deposits and redemptions, filterable and
searchable, grouped by month


Tech stack


React + Vite
React Router for routing
lucide-react for icons
Plain CSS with a shared design-token file (theme.css) — no CSS framework
